# GitPanel

Aplicativo desktop em Rust para gerenciar e acompanhar repositórios do GitHub: listar os repositórios acessíveis, criar repositórios, sincronizar commits, navegar por arquivos, branches e releases, visualizar a frequência de commits em gráficos e inspecionar diffs de código.

A interface usa egui/eframe, é escrita em português — com estrutura pronta para novos idiomas — e autentica pelo GitHub CLI (`gh`), mantendo o token apenas em memória.
